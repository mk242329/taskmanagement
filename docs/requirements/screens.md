# 画面要件

作成日：2026年10月5日
更新日：2026年10月10日（リマインド通知をやめたため、SC-04・SC-05 を欠番にした）

各画面で「何を表示し、何ができるか」をまとめる。レイアウトと画面の移り変わりは [画面設計](../design/screen-design.md) にまとめる。見た目の模型は [画面レイアウト（モックアップ）](https://claude.ai/artifact/3G96XQhTYFqzfCbgry2K3h) で確認できる。

画面に表示する文字では、カードを「タスク」と呼ぶ（例：「＋ タスクを追加」「タスクの編集」）。この資料の中では、画面の部品として「カード」と呼ぶ。

## 1. 画面一覧

画面は3つ。SC-04（通知許可ダイアログ）と SC-05（リマインド通知）は、リマインド通知を作らないことにしたため欠番にした。

| 画面ID | 画面名 | 種類 | 概要 |
| --- | --- | --- | --- |
| SC-01 | ボード画面 | メイン画面 | 3つのリストとカードを表示する。アプリを開くと最初に表示される |
| SC-02 | カード編集ウィンドウ | ウィンドウ | カードの追加と編集に使う。ボード画面の上に重ねて表示する |
| SC-03 | 削除確認ダイアログ | ダイアログ | カードを削除してよいか確認する |

## 2. 画面ごとの要件

### SC-01 ボード画面

**表示する情報**

- アプリ名「タスク管理」
- 「未着手」「作業中」「完了」の3つのリストと、それぞれのカードの枚数
- 各カードのチェックボックス・優先度・タイトル・ゴミ箱マーク・期限。期限がないカードは期限を表示しない

**カードの表示ルール**

| 状態 | 表示 |
| --- | --- |
| 優先度：高 | 赤色のラベル |
| 優先度：中 | 黄色のラベル |
| 優先度：低 | 灰色のラベル |
| 完了リストのカード | チェックボックスにチェックが付いた状態 |
| 未着手・作業中リストのカード | チェックボックスにチェックが付いていない状態 |
| 期限なし | 期限の欄を表示しない |
| 期限切れ（完了リスト以外） | カードの枠と期限の文字を赤色にする |

優先度は期限と時間厳守から自動で決まる（[機能要件](functional.md) の F-10）。時間が経って期限が近づくと、表示中のラベルも自動で変わる。

**できる操作**

- 「＋ タスクを追加」を押すと、SC-02 を追加として開く（F-02）
- カードをクリックすると、SC-02 を編集として開く（F-03）
- カードのゴミ箱マークを押すと、SC-03 を開く（F-04）。編集ウィンドウは開かない
- カードをドラッグして、別のリストへ移動する・同じリストの中で並び替える（F-05、F-06）
- カードのチェックボックスにチェックを付けると、次のリスト（未着手→作業中→完了）へ移る。完了のカードのチェックを外すと、作業中へ戻る（F-11）

### SC-02 カード編集ウィンドウ

**表示する情報**

- 見出し：追加のときは「タスクの追加」、編集のときは「タスクの編集」
- 入力項目

| 項目 | 入力方法 | 必須 | 初期値 |
| --- | --- | --- | --- |
| タイトル | 1行の入力欄 | 必須 | 空（編集のときは今の値） |
| 説明文 | 複数行の入力欄 | 任意 | 空（編集のときは今の値） |
| 期限 | 日付と時刻の入力欄 | 任意 | 空（編集のときは今の値） |
| 時間厳守 | チェックボックス | 任意 | 付けない（編集のときは今の値） |

優先度は入力しない。入力中の期限と時間厳守から決まる優先度を、ラベルで表示する。期限や時間厳守を変えると、その場で表示が変わる。

文字数などの入力ルールは [機能要件](functional.md) の「1. 共通のルール」に従う。

**できる操作**

- 「保存」：入力内容を保存して SC-01 に戻る。入力に誤りがあるときは保存しない
- 「キャンセル」：保存せずに SC-01 に戻る
- 「削除」：SC-03 を開く。編集のときだけ表示する

**エラーの表示**

入力に誤りがあるときは、タイトルの入力欄を赤い枠にし、その下にエラーメッセージを赤字で表示する。

### SC-03 削除確認ダイアログ

- 「このタスクを削除しますか？」と表示する
- 「OK」：カードを削除して SC-01 に戻る
- 「キャンセル」：削除せずに元の画面に戻る（SC-02 から開いたときは SC-02、ゴミ箱マークから開いたときは SC-01）
- アプリの見た目に合わせて作る（ブラウザ標準のダイアログは使わない）。押し間違えで消えないよう、開いたときは「キャンセル」を選んでおく
