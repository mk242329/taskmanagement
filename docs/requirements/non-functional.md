# 非機能要件

作成日：2026年10月5日
更新日：2026年10月6日（サーバーと PostgreSQL を使う構成に変更）
更新日：2026年10月10日（リマインド通知をやめたため、通知の許可を削除）
更新日：2026年11月4日（保存先を PostgreSQL から DynamoDB に変更。AWS で動かすときの条件を追記）

[要件定義書](../requirements.md) のうち、機能以外の条件（動く環境・速さ・保存・セキュリティ）をまとめる。

画面（React）とサーバー（Spring Boot）に分け、データは DynamoDB に保存する。開発中は自分のパソコンの中で動かす。ログイン機能がないため、AWS に載せるときは入口（CloudFront）で自分の PC の IP アドレスか確かめ、Basic 認証をかけて、自分だけが使う。AWS の料金がかからないよう、無料枠（Always Free）の範囲で動かす。

| 項目 | 内容 |
| --- | --- |
| 対応ブラウザ | パソコン版 Google Chrome の最新版のみ。Safari、Edge では動作確認をしない |
| 対応画面 | パソコンのみ（画面の横幅 1024px 以上）。スマホは対象外 |
| 動作の速さ | 操作してから画面に反映されるまで1秒以内（サーバーへの保存を含む） |
| データの保存先 | 開発中は DynamoDB Local（自分のパソコンの Docker 上で動かす）、AWS では DynamoDB |
| バックアップ | なし |
| 動かす場所 | 自分のパソコンのみ（`localhost`）。インターネットには公開しない |
| セキュリティ | 個人情報やパスワードは入力しない前提とする。入力内容はサーバー側でもチェックする |

使う技術の詳細は [技術スタック](../design/tech-stack.md) にまとめる。
