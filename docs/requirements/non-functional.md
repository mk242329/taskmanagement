# 非機能要件

作成日：2026年10月5日
更新日：2026年10月6日（サーバーと PostgreSQL を使う構成に変更）
更新日：2026年10月10日（リマインド通知をやめたため、通知の許可を削除）
更新日：2026年11月4日（保存先を PostgreSQL から DynamoDB に変更。AWS で動かすときの条件を追記）
更新日：2026年11月4日（動かす場所を AWS に合わせる。公開範囲・費用・インフラの管理を追記）

[要件定義書](../requirements.md) のうち、機能以外の条件（動く環境・速さ・保存・セキュリティ・運用）をまとめる。

画面（React）とサーバー（Spring Boot）に分け、データは DynamoDB に保存する。開発中は自分のパソコンの中で動かす。AWS では EC2 を 1 台置いて動かす。ログイン機能がないため、セキュリティグループで自分の PC の IP アドレスからだけつなげるようにして、自分だけが使う。

| 項目 | 内容 |
| --- | --- |
| 対応ブラウザ | パソコン版 Google Chrome の最新版のみ。Safari、Edge では動作確認をしない |
| 対応画面 | パソコンのみ（画面の横幅 1024px 以上）。スマホは対象外 |
| 動作の速さ | 操作してから画面に反映されるまで1秒以内（サーバーへの保存を含む） |
| データの保存先 | 開発中は DynamoDB Local（自分のパソコンの Docker 上で動かす）、AWS では DynamoDB |
| バックアップ | なし |
| 動かす場所 | 開発中は自分のパソコン（`localhost`）。AWS では東京リージョンの EC2 1 台で、画面と API を動かす |
| 公開範囲 | 自分の PC の IP アドレスからだけ、画面（HTTP）と SSH につなげる。それ以外からはつながらない。API のサーバー（8080）とデータベースは外に開けない |
| 通信の暗号化 | 自分の PC と EC2 の間は HTTP（暗号化しない）。自分の PC からだけつなぐため、独自のドメインと HTTPS は使わない |
| セキュリティ | 個人情報やパスワードは入力しない前提とする。入力内容はサーバー側でもチェックする。AWS の認証情報（アクセスキー・パスワード）をコードや EC2 に置かない |
| 費用 | AWS の料金がほぼかからないこと（無料枠・無料トライアルの範囲に収める）。使わないあいだは EC2 を止める |
| 可用性 | 止まっても困らない個人用のため、EC2・DB は 1 台だけにする。EC2 を止めている間は使えない |
| インフラの管理 | AWS の環境はすべて Terraform のコードで作り、変更の前に必ず差分を確かめる。マネジメントコンソールで手作業の変更はしない |

使う技術の詳細は [技術スタック](../design/tech-stack.md) にまとめる。
