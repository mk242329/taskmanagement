# 機能一覧

作成日：2026年10月5日

[要件定義書](../requirements.md) で決めた、最初のバージョンで作る機能の一覧。各機能のルールは [機能要件](functional.md) にまとめる。

## 1. 機能一覧

必須機能は9つ。すべて最初のバージョンで作る。

| No. | 機能 | 内容 | 関連する画面 |
| --- | --- | --- | --- |
| F-01 | ボード表示 | 「未着手」「作業中」「完了」の3つのリストを横に並べて表示する | SC-01 |
| F-02 | カード追加 | 各リストにカードを追加する。タイトルは必須 | SC-01、SC-02 |
| F-03 | カード編集 | タイトル・説明文・優先度・期限を後から変更する | SC-01、SC-02 |
| F-04 | カード削除 | カードを削除する。削除前に確認を表示する | SC-02、SC-03 |
| F-05 | リスト間の移動 | ドラッグ＆ドロップでカードを別のリストへ移動する | SC-01 |
| F-06 | リスト内の並び替え | ドラッグ＆ドロップで同じリスト内のカードの順番を入れ替える | SC-01 |
| F-07 | データ保存 | 変更のたびに自動で保存し、ブラウザを閉じても内容が残る | ― |
| F-08 | リマインド通知 | 期限の時刻になると、ブラウザ通知を表示する | SC-04、SC-05 |
| F-09 | 期限切れの表示 | 期限を過ぎた未完了のカードを赤色で目立たせる | SC-01 |

画面IDは [画面要件](screens.md) の画面一覧に対応する。
