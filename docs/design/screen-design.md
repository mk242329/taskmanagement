# 画面設計

作成日：2026年10月5日
更新日：2026年10月10日（リマインド通知をやめたため、SC-04・SC-05 を削除）

[画面要件](../requirements/screens.md) で決めた画面を、どのように配置し、どう移り変わるかをまとめる。表示する情報や表示ルールは画面要件を参照する。

## 1. 画面遷移図

```mermaid
flowchart TD
    Start([アプリを開く]) --> SC01

    SC01[SC-01 ボード画面]
    SC02[SC-02 カード編集ウィンドウ]
    SC03{{SC-03 削除確認ダイアログ}}

    SC01 -- 「＋ タスクを追加」を押す --> SC02
    SC01 -- カードをクリック --> SC02
    SC02 -- 「保存」を押す --> SC01
    SC02 -- 「キャンセル」を押す --> SC01
    SC01 -- ゴミ箱マークを押す --> SC03
    SC02 -- 「削除」を押す --> SC03
    SC03 -- 「OK」を押す --> SC01
    SC03 -- 「キャンセル」を押す<br>（開いた画面に戻る） --> SC02
```

- カードの移動と並び替えは、ボード画面の中でドラッグまたはチェックボックスで行うため、画面は切り替わらない

## 2. 画面レイアウト

### 2.1 SC-01 ボード画面

```text
┌─────────────────────────────────────────────────┐
│  タスク管理                                      │ ← ①
├───────────────┬───────────────┬─────────────────┤
│ 未着手 (2)     │ 作業中 (1)     │ 完了 (1)         │ ← ②
│ ┌───────────┐ │ ┌───────────┐ │ ┌─────────────┐ │
│ │□[高] 課題A │ │ │□[中] 資料作成│ │ │■[低] 本を返す│ │ ← ③
│ │ 9/30 20:00 │ │ │ 10/1 18:00 │ │ │             │ │
│ └───────────┘ │ └───────────┘ │ └─────────────┘ │
│ ＋ タスクを追加 │ ＋ タスクを追加 │ ＋ タスクを追加   │ ← ④
└───────────────┴───────────────┴─────────────────┘
```

| No. | 項目 | 配置 |
| --- | --- | --- |
| ① | ヘッダー | 画面の一番上に、横幅いっぱいに置く |
| ② | リスト名 | 各リストの一番上に置く。リスト名のあとに（ ）でカードの枚数を付ける |
| ③ | カード | リスト名の下に縦に並べる。1行目にチェックボックス・優先度ラベル・タイトル、右端にゴミ箱マーク、2行目に期限を置く。図の □ はチェックなし、■ はチェックありを表す。ゴミ箱マークは普段は薄い灰色で、マウスを乗せると赤くする |
| ④ | 追加ボタン | 各リストのカードの一番下に置く |

3つのリストは横に並べる。カードの色分けは [画面要件](../requirements/screens.md) の「カードの表示ルール」に従う。

### 2.2 SC-02 カード編集ウィンドウ

```text
┌──────────────────────────────┐
│ タスクの追加 / タスクの編集    │ ← ①
│ タイトル（必須） [__________] │ ← ②
│ 説明文         [__________]  │ ← ③
│                [__________]  │
│ 期限           [日付と時刻]   │ ← ④
│ 時間厳守       [✓] 遅れては… │ ← ⑤
│ 優先度         [高] 自動で…  │ ← ⑥
│                              │
│ [削除]        [キャンセル][保存] │ ← ⑦
└──────────────────────────────┘
```

| No. | 項目 | 配置 |
| --- | --- | --- |
| ① | 見出し | ウィンドウの一番上に置く |
| ② | タイトル | 項目名を左、入力欄を右に置く。エラーメッセージは入力欄のすぐ下に置く |
| ③ | 説明文 | 複数行の入力欄にする |
| ④ | 期限 | 日付と時刻をまとめて入力できる欄にする |
| ⑤ | 時間厳守 | チェックボックスにし、横に「優先度が1段階上がる」ことを書く |
| ⑥ | 優先度 | 入力欄は置かず、自動で決まった優先度のラベルと「期限と時間厳守から自動で決まります」の説明を置く |
| ⑦ | ボタン | 「削除」を左端、「キャンセル」「保存」を右端に置く |

ウィンドウはボード画面の上に重ねて表示する。入力項目とエラーの扱いは [画面要件](../requirements/screens.md) の SC-02 に従う。

### 2.3 SC-03 削除確認ダイアログ

```text
┌──────────────────────────┐
│ このタスクを削除しますか？   │
│                          │
│         [キャンセル][OK]  │
└──────────────────────────┘
```

「このタスクを削除しますか？」の文と、「キャンセル」「OK」のボタンだけを置く。アプリの見た目に合わせて作り、SC-02 と同じくボード画面（または SC-02）の上に重ねて表示する。「OK」は取り消せない操作のため赤色にする。
