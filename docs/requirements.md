# Trello風タスク管理アプリ 要件定義書

作成日：2026年9月26日

## 1. 概要

自分ひとりで仕事のタスクや勉強の進み具合を管理するための、Trello風のタスク管理アプリを作る。スクールの課題として開発する。

| 項目 | 内容 |
| --- | --- |
| 目的 | タスクを「未着手・作業中・完了」の3つのリストで見える化し、期限を忘れないようにする |
| 利用者 | 自分ひとり |
| 用途 | 仕事のタスク、勉強の進み具合の管理 |
| 背景 | スクールの課題 |

## 2. スコープ

最初のバージョンでは、カードの基本操作・並び替え・保存・リマインド通知だけを作る。

**今回作るもの**

- カードの追加・編集・削除
- カードのリスト間の移動と、リスト内の並び替え
- ブラウザへのデータ保存
- 期限時刻のブラウザ通知
- 期限切れカードの色分け

**今回作らないもの**

- ログイン、他の人との共有
- 担当者の割り当て
- 複数ボード
- リストの追加・名前変更
- ブラウザを閉じている間の通知（サーバーが必要になるため）

## 3. 機能要件

必須機能は9つ。すべて最初のバージョンで作る。

| No. | 機能 | 内容 |
| --- | --- | --- |
| F-01 | ボード表示 | 「未着手」「作業中」「完了」の3つのリストを横に並べて表示する |
| F-02 | カード追加 | 各リストにカードを追加する。タイトルは必須 |
| F-03 | カード編集 | タイトル・説明文・優先度・期限を後から変更する |
| F-04 | カード削除 | カードを削除する。削除前に確認を表示する |
| F-05 | リスト間の移動 | ドラッグ＆ドロップでカードを別のリストへ移動する |
| F-06 | リスト内の並び替え | ドラッグ＆ドロップで同じリスト内のカードの順番を入れ替える |
| F-07 | データ保存 | 変更のたびに自動で保存し、ブラウザを閉じても内容が残る |
| F-08 | リマインド通知 | 期限の時刻になると、ブラウザ通知を表示する |
| F-09 | 期限切れの表示 | 期限を過ぎた未完了のカードを赤色で目立たせる |

## 4. データ項目

カードは次の項目を持つ。リストは3つ固定のため、利用者が変更できる項目はない。

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| タイトル | 必須 | タスクの名前 |
| 説明文 | 任意 | タスクの詳しい内容やメモ |
| 優先度 | 任意 | 高・中・低 の3段階 |
| 期限 | 任意 | 日付と時刻。リマインド通知にも使う |
| 所属リスト | 自動 | 未着手・作業中・完了 のどれか |
| 表示順 | 自動 | リスト内の並び順 |

## 5. 非機能要件

サーバーを使わず、ブラウザだけで動くアプリにする。

| 項目 | 内容 |
| --- | --- |
| 動作環境 | パソコンの最新版ブラウザ（Chrome など） |
| データの保存先 | ブラウザの localStorage。保存したブラウザでしか見られない |
| 通知の条件 | アプリのタブを開いている間のみ届く。別のタブや別のアプリを使っていても届く |
| 通知の許可 | 初回利用時に、ブラウザの通知許可を求める |

## 6. 将来追加したい機能

最初のバージョンが完成したあと、必要に応じて追加する。

- 優先度や期限の順にカードを自動で並べ替える
- リストの追加・名前変更
- ラベル（色分け）
- 複数ボード
- コメント・チェックリスト
- ブラウザを閉じていても届く通知（サーバーが必要）
- ログイン・他の人との共有
