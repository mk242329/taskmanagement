# Trello風タスク管理アプリ テスト仕様書

作成日：2026年9月26日
更新日：2026年10月6日（サーバーと PostgreSQL を使う構成に合わせて、テスト環境とデータの消し方を変更）

[要件定義書](requirements.md) の機能 F-01〜F-11 と詳細ルール（[機能一覧](requirements/features.md)、[機能要件](requirements/functional.md)）が、要件どおりに動くかを確認する手順をまとめる。すべての項目が「OK」になったら完成とする（要件定義書「5. 受け入れ基準」）。

## 1. テスト環境

| 項目 | 内容 |
|---|---|
| パソコン | Mac |
| ブラウザ | Google Chrome の最新版 |
| アプリの起動 | ① `docker compose up -d` で PostgreSQL を起動する<br>② `backend/` で `./mvnw spring-boot:run` を実行し、サーバーを起動する<br>③ `frontend/` で `npm run dev` を実行し、画面を起動する |
| アプリの開き方 | Chrome で `http://localhost:5173` を開く |
| 画面の横幅 | 1024px 以上 |

## 2. テストの進め方

- テストは、表の上から順番に行う
- 「結果」の欄に OK / NG を書く。NG のときは、何が起きたかを「メモ」に書く
- 「データなし」から始める項目は、先に次の手順でデータを消しておく
  1. ターミナルでプロジェクトのフォルダを開く
  2. `docker compose exec db psql -U taskapp -d taskapp -c "DELETE FROM card;"` を実行し、カードをすべて消す
  3. Chrome でアプリのページを再読み込みする
- 通知のテストでは、期限を「今から2分後」のように近い時刻にすると早く確認できる
